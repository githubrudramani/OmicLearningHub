A learning path, from counts to tissue

New to omics analysis? Follow the modules in order. Each one builds on the ideas of the one before. If you already know the basics, jump straight to the module you need.

  1. 0

    Before you start

    The ideas every module relies on:

    • Count matrix and sample metadata
    • Biological replicates vs. technical batches
    • Normalisation and experimental design
  2. 1

    Bulk RNA-seq

    Filtering, TMM, limma-voom, contrasts, pathway analysis. The foundation for everything else.

  3. 2

    Single-cell RNA-seq

    QC, clustering, Harmony integration, cell-type annotation, donor-level comparisons.

  4. 3

    Spatial transcriptomics

    Tissue coordinates, segmentation, neighbourhoods, spatial study design, plus a real multi-slide project.

About

About this hub

OmicLearningHub is a free, open set of tutorials for analysing omics data. Every module pairs concepts with code you can copy, and says plainly how far that code has been tested. The source is public on GitHub, so corrections are welcome.

Maintained by githubrudramani on GitHub.

Found a mistake or have a question?

Open an issue on GitHub and name the module and step. Every page links straight to a pre-filled issue.
