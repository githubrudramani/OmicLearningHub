Part 1 · Concepts

What is spatial omics?

Single-cell RNA-seq tells you which cells are in a sample and what they express, but it dissociates the tissue first, so every cell's location is lost. Spatial omics measures RNA (and increasingly protein) in place, on an intact tissue section. Each measurement keeps its x/y coordinate.

That coordinate is what makes new questions answerable. Which immune cells actually touch the tumour? Is a fibroblast state confined to the invasive margin? Do two cell types always appear together in the same micro-environment? These are questions about neighbourhoods, and you can only ask them when location is preserved.

Imaging-based (in situ)

Fluorescent probes bind target RNAs directly in the tissue. A microscope images the slide over many cycles, and each transcript's colour code is decoded into a gene name and a position.

  • Single-cell and subcellular resolution
  • Targeted gene panels (hundreds to a few thousand genes; some now reach whole transcriptome)
  • Examples: Xenium, CosMx, MERSCOPE

Sequencing-based (capture)

Transcripts are captured onto a slide covered in spatially barcoded spots or bins. The library is sequenced, and the barcode tells you where each read came from.

  • Unbiased whole transcriptome
  • Resolution set by spot or bin size (55 µm down to 2 µm or less)
  • Examples: Visium / Visium HD, Stereo-seq, Curio Seeker

Part 2 · The landscape, October 2026

Who makes what, and where each one fits

Specs below come from vendor material and published benchmarks. Detection efficiency and false-positive rates depend heavily on tissue, panel and chemistry version, so treat them as a starting point and pilot on your own samples.

Xenium (Xenium Prime 5K, Xenium Protein)

Imaging
Chemistry
Padlock probes + rolling-circle amplification, cyclic imaging
Plex
Pre-designed panels (~300–480 genes) up to 5,000 genes (Prime 5K) + up to 100 custom; RNA + protein on the same section with Xenium Protein
Resolution
Subcellular; per-transcript coordinates
Samples
FFPE, fresh-frozen
Run time
About 3 days (480-plex) to under 6 days (5K); 2 slides per run

Advantages

Xenium analysis pipeline in R

Built on the 10x Genomics Xenium downstream analysis in R guide (Seurat v5, BPCells sketching, Harmony, Banksy), with extra steps for quality control, re-segmentation, reference-based annotation and niche analysis. Tick steps off as you go; your progress is saved in this browser.

01

Setup

Install the R toolkit

Seurat v5 reads Xenium bundles directly. BPCells keeps large matrices on disk so a 1M-cell Prime 5K run fits on a laptop. Harmony corrects batch effects; Banksy adds spatially aware clustering; spacexr gives reference-based cell typing.

R
# R ≥ 4.3 recommended
install.packages(c("Seurat", "remotes", "arrow", "dplyr", "ggplot2", "harmony"))
remotes::install_github("bnprks/BPCells/r")           # on-disk matrices
remotes::install_github("satijalab/seurat-wrappers")  # RunBanksy()
remotes::install_github("prabhakarlab/Banksy")
remotes::install_github("dmcable/spacexr")            # RCTD annotation

library(Seurat); library(dplyr); library(ggplot2)
options(future.globals.maxSize = 8 * 1024^3)          # 8 GB for big objects
ComputeA Xenium v1 run (~300k cells) needs ~32 GB RAM. A Prime 5K run with ~1M cells is comfortable at 64–128 GB, or use the sketch workflow in step 09. On AWS that is roughly an r6i.2xlarge to r6i.4xlarge instance.
02

Data

Get the data and learn the output bundle

Download the Xenium Prime 5K Human Breast Cancer (FFPE) dataset from the 10x Datasets page (filter by Xenium). Unzip it and you get the outs/ folder the instrument produces. Knowing these files matters more than any one package.

outs/
├── experiment.xenium            # run metadata; open this in Xenium Explorer
├── metrics_summary.csv          # run-level QC: median transcripts/cell, decoded counts
├── cell_feature_matrix.h5       # cells × genes counts (plus control probes/codewords)
├── cells.parquet                # per-cell centroid, area, nucleus area, counts
├── transcripts.parquet          # every decoded transcript: gene, x, y, z, qv, cell_id
├── cell_boundaries.parquet      # segmentation polygons
├── nucleus_boundaries.parquet
├── morphology_focus/            # DAPI + multimodal segmentation stain images (OME-TIFF)
└── analysis/                    # instrument's own clustering, UMAP, DE
Shell
# paste the "Output files" link from the dataset page
curl -O "<URL of the Xenium output bundle .zip>"
unzip Xenium_Prime_Human_Breast_*_outs.zip -d breast_5k
head -5 breast_5k/outs/metrics_summary.csv
TipSome older tools want transcripts.csv.gz. Convert with arrow::read_parquet("transcripts.parquet") |> data.table::fwrite("transcripts.csv.gz"). Recent Seurat reads Parquet directly.
03

Import

Load Xenium into Seurat

LoadXenium() builds a Seurat object with the gene counts, cell centroids, segmentation boundaries and transcript coordinates in one spatial "field of view" (FOV). Low-quality transcripts (QV < 20) are dropped at import.

R
xen <- LoadXenium("breast_5k/outs", fov = "fov", assay = "Xenium")
xen
Assays(xen)        # Xenium + BlankCodeword / ControlCodeword / ControlProbe

# add per-cell morphology (area) from cells.parquet
cells <- arrow::read_parquet("breast_5k/outs/cells.parquet")
xen$cell_area    <- cells$cell_area[match(colnames(xen), cells$cell_id)]
xen$nucleus_area <- cells$nucleus_area[match(colnames(xen), cells$cell_id)]
04

QC

Quality control: cells, controls and run metrics

Imaging data has its own failure modes: empty segmentations, tiny debris "cells", and off-target signal. Negative-control probes and blank codewords estimate the false-positive rate. Thresholds depend on panel size, so look at the distributions before you choose cutoffs.

R
VlnPlot(xen, features = c("nFeature_Xenium", "nCount_Xenium", "cell_area"),
        ncol = 3, pt.size = 0)

# false-positive estimate: control signal relative to real genes
ctrl <- colSums(LayerData(xen, assay = "ControlProbe", layer = "counts")) +
        colSums(LayerData(xen, assay = "BlankCodeword", layer = "counts"))
xen$pct_control <- 100 * ctrl / (xen$nCount_Xenium + ctrl)
summary(xen$pct_control)                       # aim for a median well under 1%

# filter: thresholds for a 5K panel; use ~10 counts / 5 genes for a ~300-gene panel
xen <- subset(xen, subset = nCount_Xenium >= 50 & nFeature_Xenium >= 25 &
                            pct_control < 5 & cell_area > 10)
ncol(xen)
CheckpointCompare your median transcripts per cell with metrics_summary.csv. Map the removed cells with ImageDimPlot(): if they cluster in one region, suspect a tissue fold or detachment, not biology.
05

Segmentation · newer practice

Re-segment cells if boundaries look wrong

Every downstream result inherits the segmentation. Nuclear expansion can assign one cell's transcripts to its neighbour, which shows up as "doublet" clusters such as T cells expressing epithelial keratins. Recent runs use multimodal segmentation (boundary, interior and nuclear stains). For older data, or crowded tissue, re-segment.

Shell
# Xenium Ranger (free from 10x): change nuclear expansion distance
xeniumranger resegment --id=breast_reseg \
  --xenium-bundle=breast_5k/outs --expansion-distance=5

# or import a segmentation made elsewhere (Cellpose, Baysor, Proseg)
xeniumranger import-segmentation --id=breast_cellpose \
  --xenium-bundle=breast_5k/outs --cells=cellpose_masks.tif
2025–26 trendTranscript-based segmenters (Proseg, Baysor, segger) place cell boundaries using the transcripts themselves, not just the stain. They usually reduce contamination between neighbouring cells. Compare marker co-expression before and after to judge the gain.
06

Core analysis

Normalise, reduce and cluster

Targeted panels are not a random sample of the transcriptome, so use every gene as a feature rather than picking variable genes. SCTransform handles the depth differences between small and large cells well.

R
xen <- SCTransform(xen, assay = "Xenium")
xen <- RunPCA(xen, npcs = 30, features = rownames(xen))
ElbowPlot(xen, ndims = 30)
xen <- RunUMAP(xen, dims = 1:30)
xen <- FindNeighbors(xen, reduction = "pca", dims = 1:30)
xen <- FindClusters(xen, resolution = 0.3)

DimPlot(xen, label = TRUE) + NoLegend()
ChooseFor >500k cells, SCTransform gets slow. Use NormalizeData() + ScaleData(), or the sketch workflow in step 09. Try resolutions from 0.2 to 1.0; with 5,000 genes you can resolve finer subtypes than with a 300-gene panel.

Annotation

Find markers and annotate cell types

Start with marker genes per cluster, as in the 10x guide. Then confirm with a reference: label transfer from a matched scRNA-seq atlas is now standard and catches mixed clusters that markers alone miss.

R · markers
xen <- PrepSCTFindMarkers(xen)
markers <- FindAllMarkers(xen, only.pos = TRUE, logfc.threshold = 0.25, min.pct = 0.1)
top5 <- markers |> group_by(cluster) |> slice_max(avg_log2FC, n = 5)
DotPlot(xen, features = unique(top5$gene)) + RotatedAxis()

# name clusters from markers (example map; fill in from your DotPlot)
labels <- c("0" = "Tumour epithelium", "1" = "CAF", "2" = "Macrophage",
            "3" = "T cell", "4" = "Endothelial", "5" = "B / plasma")
xen$celltype <- unname(labels[as.character(xen$seurat_clusters)])
R · reference (RCTD)
library(spacexr)
# ref_seurat: a matched scRNA-seq reference with a "celltype" column
ref <- Reference(LayerData(ref_seurat, layer = "counts"),
                 factor(ref_seurat$celltype))
coords <- GetTissueCoordinates(xen[["fov"]], which = "centroids")
rownames(coords) <- coords$cell
query <- SpatialRNA(coords[, c("x", "y")],
                    LayerData(xen, assay = "Xenium", layer = "counts"))
rctd <- create.RCTD(query, ref, max_cores = 8, UMI_min = 20)
rctd <- run.RCTD(rctd, doublet_mode = "doublet")   # models 1–2 types per cell
res <- rctd@results$results_df
xen$rctd_type <- as.character(res$first_type[match(colnames(xen), rownames(res))])
ExportLoad labels back into Xenium Explorer: write.csv(data.frame(cell_id = colnames(xen), group = xen$celltype), "celltypes.csv", row.names = FALSE, quote = FALSE), then Cell → Add cell categorization.
09

Scale

Integrate several samples with sketching and Harmony

Two Prime 5K slides can exceed a million cells. The 10x guide keeps the full matrices on disk with BPCells, learns structure on a 50,000-cell "sketch", corrects batch effects with Harmony, then projects the result back onto every cell.

R
library(BPCells)
samples <- c(breast = "breast_5k/outs", cervix = "cervix_5k/outs")

mats <- lapply(names(samples), function(s) {
  m <- open_matrix_10x_hdf5(file.path(samples[[s]], "cell_feature_matrix.h5"),
                            feature_type = "Gene Expression")
  colnames(m) <- paste0(s, "_", colnames(m))           # unique cell IDs
  write_matrix_dir(m, dir = file.path("bpcells", s), overwrite = TRUE)
  open_matrix_dir(file.path("bpcells", s))
})
names(mats) <- names(samples)

obj <- CreateSeuratObject(counts = mats)               # one layer per sample
obj$sample <- sub("_.*", "", colnames(obj))
obj <- NormalizeData(obj) |> FindVariableFeatures()

obj <- SketchData(obj, ncells = 50000, method = "LeverageScore",
                  sketched.assay = "sketch")
DefaultAssay(obj) <- "sketch"
obj <- FindVariableFeatures(obj) |> ScaleData() |> RunPCA(npcs = 30)
obj <- IntegrateLayers(obj, method = HarmonyIntegration,
                       orig.reduction = "pca", new.reduction = "harmony")
obj <- FindNeighbors(obj, reduction = "harmony", dims = 1:30) |>
       FindClusters(resolution = 0.5)
obj <- RunUMAP(obj, reduction = "harmony", dims = 1:30, return.model = TRUE)

# project sketch → all cells
obj <- ProjectIntegration(obj, sketched.assay = "sketch", assay = "RNA",
                          reduction = "harmony")
obj <- ProjectData(obj, sketched.assay = "sketch", assay = "RNA",
                   sketched.reduction = "harmony.full", full.reduction = "harmony.full",
                   dims = 1:30, refdata = list(cluster_full = "seurat_clusters"))
DefaultAssay(obj) <- "RNA"
DimPlot(obj, reduction = "full.umap", group.by = c("sample", "cluster_full"))
ThenSubset to one compartment (for example macrophages) and re-cluster to find states such as SPP1⁺ versus C1Q⁺ tumour-associated macrophages. This is the final section of the 10x guide.
10

Spatial

Find tissue domains with Banksy

Standard clustering ignores location. Banksy adds each cell's neighbourhood expression to its own. With a low λ it refines cell types; with a high λ it finds tissue domains such as tumour core, invasive margin, stroma and tertiary lymphoid structures.

R
library(SeuratWrappers); library(Banksy)

cent <- GetTissueCoordinates(xen[["fov"]], which = "centroids")
xen$sx <- cent$x[match(colnames(xen), cent$cell)]
xen$sy <- cent$y[match(colnames(xen), cent$cell)]

xen <- RunBanksy(xen, lambda = 0.8, assay = "SCT", slot = "data",
                 features = "all", dimx = "sx", dimy = "sy", k_geom = 30)
xen <- RunPCA(xen, assay = "BANKSY", reduction.name = "pca.banksy",
              features = rownames(xen), npcs = 30)
xen <- FindNeighbors(xen, reduction = "pca.banksy", dims = 1:30)
xen <- FindClusters(xen, resolution = 0.5, cluster.name = "banksy_domain")
ImageDimPlot(xen, group.by = "banksy_domain", cols = "polychrome", size = 0.6)
λ guidelambda = 0.2 for cell typing; lambda = 0.8 for domains. Alternatives worth knowing: CellCharter, and the deep-learning model Novae.

Spatial · newer practice

Cellular niches and neighbourhood enrichment

A niche is defined by which cell types surround a cell. Seurat counts the annotated types among each cell's 30 nearest neighbours and clusters those compositions. Then test which pairs of cell types sit together more often than chance.

R
xen <- BuildNicheAssay(xen, fov = "fov", group.by = "celltype",
                       niches.k = 6, neighbors.k = 30)
ImageDimPlot(xen, group.by = "niches", size = 0.6, dark.background = FALSE)

# composition of each niche
table(xen$celltype, xen$niches) |> prop.table(margin = 2) |> round(2)
Python track: neighbourhood enrichment with squidpy
Python
import spatialdata_io as sdio, scanpy as sc, squidpy as sq

sdata = sdio.xenium("breast_5k/outs")          # images, shapes, points + table
adata = sdata.tables["table"]
sc.pp.filter_cells(adata, min_counts=50)
sc.pp.normalize_total(adata); sc.pp.log1p(adata)
sc.pp.pca(adata); sc.pp.neighbors(adata); sc.tl.umap(adata)
sc.tl.leiden(adata, resolution=0.5)

sq.gr.spatial_neighbors(adata, coord_type="generic", delaunay=True)
sq.gr.nhood_enrichment(adata, cluster_key="leiden")
sq.pl.nhood_enrichment(adata, cluster_key="leiden")
sq.gr.co_occurrence(adata, cluster_key="leiden")

Part 4 · Keeping current

What changed in spatial analysis, 2025–2026

Panels

Thousands of genes, plus protein

Xenium Prime 5K, CosMx 6K and Whole Transcriptome, and same-section protein (Xenium Protein, CosMx multiomics) blur the line between targeted and discovery work.

Segmentation

Better cell boundaries

Multimodal stains on-instrument and transcript-aware tools (Proseg, Baysor, segger) reduce mixing between neighbouring cells, which was the largest source of error in early studies.

Scale

Million-cell datasets

On-disk matrices (BPCells, SpatialData/zarr) and sketching are now the default for Prime 5K and WTX runs, not an advanced option.

Standards

SpatialData as common format

The scverse SpatialData format holds images, transcripts, shapes and tables together, with readers for Xenium, CosMx, MERSCOPE and Visium HD. This makes cross-platform work simpler.

Models

Spatial foundation models

Models such as Nicheformer and Novae are trained on millions of spatial cells and used for annotation and domain detection. They are promising, but validate them against markers.

Integration

Combining platforms

A common design: Visium HD for whole-transcriptome discovery, then Xenium on a serial section for single-cell validation, aligned to the same H&E.

Glossary

FOV
Field of view: one imaged tile, or in Seurat the spatial container holding coordinates and boundaries.
QV
Phred-style quality score for a decoded transcript. QV 20 means about a 1% chance the gene call is wrong.
Codeword
The sequence of colours across imaging cycles that identifies a gene. Blank codewords match no gene and measure decoding errors.
Segmentation
Drawing cell boundaries so that transcripts can be assigned to cells.
Sketching
Analysing a representative subsample of cells, then projecting results onto all cells.
Niche
A recurring local mix of cell types, for example tumour cells next to SPP1⁺ macrophages and CAFs.
Bin
In sequencing-based platforms, a square of barcodes aggregated into one unit (for example 8 × 8 µm in Visium HD).
