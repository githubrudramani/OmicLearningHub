Learning hub · Module 3 · Single-cell

Single-cell RNA-seq with Harmony integration and cell-type annotation

How single-cell sequencing developed, which platform to choose, how Harmony removes batch effects without erasing biology, and a full Seurat pipeline on real PBMC data. The pipeline uses LogNormalize (no SCTransform), Harmony integration, and automated annotation with ScType cross-checked against SingleR.

Part 1 · History

How single-cell RNA-seq evolved

In fifteen years the field went from sequencing one cell to sequencing a hundred million. Most of the gains came from new ways to label each cell's RNA with a barcode: tubes, then plates, then droplets, then split-pool chemistry.

2009

First cell

Single-cell transcriptome

Tang et al. sequenced the mRNA of a single mouse blastomere. Each cell was handled by hand in its own tube.

2012–14

Plates

Smart-seq, CEL-seq, MARS-seq

Plate-based methods processed hundreds of cells, with full-length coverage (Smart-seq2) or early barcoding and UMIs to count molecules exactly (CEL-seq, MARS-seq). Nature Methods named single-cell sequencing Method of the Year 2013.

2015

Droplets

Drop-seq and inDrop

Cells were captured in oil droplets with barcoded beads, raising throughput from hundreds to tens of thousands of cells per experiment.

2016–17

Commercial scale

10x Chromium, CITE-seq, split-pool

The 10x Chromium made droplet scRNA-seq a standard kit. CITE-seq added surface proteins to the same cells. SPLiT-seq and sci-RNA-seq barcoded cells in plates without any instrument.

2018–19

Integration

Combining datasets

As studies grew to many donors and batches, integration became essential: Seurat anchors (Stuart et al.), scVI, and Harmony (Korsunsky et al., Nature Methods 2019). Harmony was fast enough for a laptop and became one of the most widely used methods.

2020–22

Multiome and atlases

More layers, shared references

Joint RNA + ATAC kits, nucleus-based protocols for frozen tissue, and reference atlases (Human Cell Atlas, Azimuth, CELLxGENE) made automated annotation practical.

2023–24

Fixed cells and millions

Probe-based and million-cell runs

Fixed-RNA probe assays (10x Flex) separated sample collection from processing, which matters for clinical work. Split-pool kits reached millions of cells per experiment. Seurat v5 added on-disk data and sketching for this scale.

2025–26

Now

Perturbation atlases and foundation models

Datasets of up to ~100 million cells, such as large drug and CRISPR perturbation screens, train single-cell foundation models (scGPT, Geneformer and successors). The core workflow you will learn below (QC, normalisation, integration, clustering, annotation) is still the foundation for using them.

Part 3 · Concept

How Harmony works

The same cell type looks slightly different in each batch. Differences in sample handling, chemistry, sequencing run or donor shift the cells in PCA space. If you cluster without correcting, you get "batch clusters" instead of cell-type clusters.

Harmony works on the PCA embedding and repeats two steps:

  1. Soft clustering with a diversity penalty. Cells are softly assigned to clusters, and clusters made of only one batch are penalised. Strength is set by theta; higher means more mixing.
  2. Correction. Within each cluster, every batch's centre is moved toward the cluster's overall centre, weighted by how strongly each cell belongs to that cluster.

It stops when the clusters stop changing. Because corrections are made per cluster, a cell type present in only one batch (the small purple group here) is not forced onto another type.

Move the slider through the iterations. Batch mixing rises while cell types stay separate.

Shape = batch (● batch 1, ▲ batch 2); colour = cell type. Purple type is rare in batch 2.

Part 4 · Hands-on tutorial

Seurat pipeline: LogNormalize → Harmony → annotation

Uses the ifnb dataset from SeuratData: about 14,000 human PBMCs (Kang et al., 2018), half in a control batch and half stimulated with interferon-β. The stimulation shifts every cell type, a strong batch-like effect that integration has to handle without losing cell identity. The dataset ships with published annotations, so you can score your own annotation against them. Progress is saved in this browser.

QC

Filter low-quality cells and doublets

Remove dying cells (high mitochondrial fraction), empty or broken droplets (few genes), and doublets (two cells in one droplet). Choose thresholds per dataset from the plots, not from a fixed rule.

R

        group.by = "stim", pt.size = 0, ncol = 3)
FeatureScatter(ifnb, "nCount_RNA", "nFeature_RNA", group.by = "stim")

ifnb <- subset(ifnb, subset = nFeature_RNA > 200 & nFeature_RNA < 2500 &
                              percent.mt < 10)

05

Normalisation

Split by batch and LogNormalize

We use Seurat's standard log-normalisation, not SCTransform. Each cell's counts are divided by its total, multiplied by 10,000, and log-transformed. It is simple, fast, transparent, and works well with Harmony. Splitting the RNA assay into one layer per batch lets Seurat select variable genes per batch.

R
ifnb[["RNA"]] <- split(ifnb[["RNA"]], f = ifnb$stim)   # layers: counts.CTRL, counts.STIM

ifnb <- NormalizeData(ifnb, normalization.method = "LogNormalize",
                      scale.factor = 10000)
ifnb <- FindVariableFeatures(ifnb, selection.method = "vst", nfeatures = 2000)
ifnb <- ScaleData(ifnb)          # optional: vars.to.regress = "percent.mt"
Why not SCTransform?Both are valid. LogNormalize keeps one clear "data" layer that marker tests, ScType, SingleR and pseudobulk all use directly. SCTransform needs extra steps (PrepSCTFindMarkers) and more memory on large datasets.

Diagnose

Look at the data before integration

Always look first. If CTRL and STIM cells form separate islands for the same cell type, integration is needed. If they already overlap, it may not be.

R
ifnb <- FindNeighbors(ifnb, dims = 1:30, reduction = "pca")

                reduction.name = "umap.unintegrated")

ExpectEach cell type splits into a CTRL island and a STIM island. That separation is the interferon response acting like a batch effect.
08

Integration

Integrate with Harmony

Harmony takes the PCA embedding and returns a corrected embedding called harmony. Every downstream step (neighbours, clusters, UMAP) uses it instead of pca. Counts and the data layer are not changed.

R · Seurat v5 interface
ifnb <- IntegrateLayers(object = ifnb, method = HarmonyIntegration,
                        orig.reduction = "pca", new.reduction = "harmony",
                        verbose = FALSE)
R · harmony package directly
# same result, with full control over parameters
ifnb <- RunHarmony(ifnb, group.by.vars = "stim", reduction.use = "pca",
                   dims.use = 1:30, theta = 2, reduction.save = "harmony")

# several batch variables, e.g. sample and chemistry:
# RunHarmony(obj, group.by.vars = c("sample", "chemistry"), theta = c(2, 1))
Which batch?Correct for technical variables (sample, lane, chemistry, donor). If you correct for your biological condition, as we do here for teaching, you must test condition effects later on the uncorrected data. Step 13 does that.

Diagnose

Check that integration worked

Good integration mixes batches within clusters but keeps cell types apart. Check both, numerically.

R
# each cluster should contain both conditions
prop.table(table(ifnb$harmony_clusters, ifnb$stim), margin = 1) |> round(2)

# LISI: iLISI ≈ 2 means two batches fully mixed; cLISI ≈ 1 means types kept apart
remotes::install_github("immunogenomics/lisi")
meta <- ifnb@meta.data[, c("stim", "seurat_annotations")]
before <- lisi::compute_lisi(Embeddings(ifnb, "pca")[, 1:30], meta, colnames(meta))
after  <- lisi::compute_lisi(Embeddings(ifnb, "harmony")[, 1:30], meta, colnames(meta))
sapply(list(before = before, after = after), colMeans)
Over-correctionIf clearly different cell types (for example CD4 T and NK cells) start to merge, lower theta or correct for fewer variables.

Annotation · automated

Annotate cell types with ScType, confirm with SingleR

ScType scores each cluster against a curated database of positive and negative marker genes for a tissue. SingleR uses a different source of evidence: correlation with a labelled reference. Where the two agree and the markers from step 11 support it, the label is reliable. Where they disagree, look closer.

R · ScType
library(HGNChelper); library(openxlsx)
source("https://raw.githubusercontent.com/IanevskiAleksandr/sc-type/master/R/gene_sets_prepare.R")
source("https://raw.githubusercontent.com/IanevskiAleksandr/sc-type/master/R/sctype_score_.R")
db <- "https://raw.githubusercontent.com/IanevskiAleksandr/sc-type/master/ScTypeDB_full.xlsx"
gs <- gene_sets_prepare(db, "Immune system")       # tissue: Immune system, Brain, Liver, ...

# ScType needs scaled values for its marker genes
feats <- union(VariableFeatures(ifnb), intersect(unlist(gs$gs_positive), rownames(ifnb)))
ifnb <- ScaleData(ifnb, features = feats)
scaled <- as.matrix(LayerData(ifnb, assay = "RNA", layer = "scale.data"))

es <- sctype_score(scRNAseqData = scaled, scaled = TRUE,
                   gs = gs$gs_positive, gs2 = gs$gs_negative)

cl <- do.call(rbind, lapply(levels(ifnb$harmony_clusters), function(k) {
  cells <- colnames(ifnb)[ifnb$harmony_clusters == k]
  s <- sort(rowSums(es[, cells, drop = FALSE]), decreasing = TRUE)
  data.frame(cluster = k, type = names(s)[1], score = s[1], ncells = length(cells))
}))
cl$type[cl$score < cl$ncells / 4] <- "Unknown"        # low-confidence clusters
ifnb$sctype <- cl$type[match(ifnb$harmony_clusters, cl$cluster)]
DimPlot(ifnb, reduction = "umap.harmony", group.by = "sctype", label = TRUE, repel = TRUE)

13

Biology

Compare conditions within each cell type

Integration helped us find matching cell types; now test the stimulation within each one. Tests use the normalised expression values, never the Harmony embedding. With biological replicates, use pseudobulk: sum counts per sample and cell type, then run limma-voom with TMM, exactly as in Module 2.

R · teaching (ifnb has no donor IDs)
ifnb$celltype.stim <- paste(ifnb$celltype, ifnb$stim, sep = "_")
Idents(ifnb) <- "celltype.stim"
mono_ifn <- FindMarkers(ifnb, ident.1 = "Classical Monocytes_STIM",   # use your label names
                        ident.2 = "Classical Monocytes_CTRL")
head(mono_ifn, 10)          # expect interferon genes: ISG15, IFIT1, IFI6, MX1
FeaturePlot(ifnb, c("ISG15", "CXCL10"), split.by = "stim", reduction = "umap.harmony")
R · real studies: pseudobulk + limma-voom
library(edgeR); library(limma)
# obj has columns: celltype, sample (donor), condition
pb <- AggregateExpression(obj, assays = "RNA", group.by = c("celltype", "sample"),
                          return.seurat = FALSE)$RNA
colnames(pb)                                  # e.g. "CD14 Mono_donor1"
mono <- pb[, startsWith(colnames(pb), "CD14 Mono_")]
smp  <- sub("^CD14 Mono_", "", colnames(mono))
cond <- factor(obj$condition[match(smp, obj$sample)])

y <- DGEList(mono, group = cond)
y <- y[filterByExpr(y), , keep.lib.sizes = FALSE]
y <- calcNormFactors(y, method = "TMM")
design <- model.matrix(~ cond)
fit <- eBayes(lmFit(voom(y, design), design))
topTable(fit, coef = 2, n = 20)
Don'tTreating each cell as an independent replicate inflates significance hugely (pseudoreplication). For publication-grade condition comparisons, use pseudobulk across donors.

Python track: the same workflow in scanpy
Python
import scanpy as sc, celltypist

adata = sc.read_h5ad("pbmc.h5ad")
sc.pp.filter_cells(adata, min_genes=200)
adata.var["mt"] = adata.var_names.str.startswith("MT-")
sc.pp.calculate_qc_metrics(adata, qc_vars=["mt"], inplace=True)
adata = adata[adata.obs.pct_counts_mt < 10].copy()
adata.layers["counts"] = adata.X.copy()

sc.pp.normalize_total(adata, target_sum=1e4); sc.pp.log1p(adata)   # = LogNormalize
sc.pp.highly_variable_genes(adata, n_top_genes=2000, batch_key="stim")
sc.pp.scale(adata, max_value=10); sc.tl.pca(adata, n_comps=50)

sc.external.pp.harmony_integrate(adata, key="stim")          # needs harmonypy
sc.pp.neighbors(adata, use_rep="X_pca_harmony", n_pcs=30)
sc.tl.leiden(adata, resolution=0.5); sc.tl.umap(adata)

pred = celltypist.annotate(adata, model="Immune_All_Low.pkl", majority_voting=True)
adata.obs["celltypist"] = pred.predicted_labels["majority_voting"]

Glossary

UMI
Unique molecular identifier: a random barcode on each captured molecule, so PCR duplicates are counted once.
Doublet
A droplet that captured two cells; it looks like a hybrid cell type.
LogNormalize
log1p(count / cell total × 10,000): Seurat's default normalisation.
Batch effect
Technical variation between groups of samples processed differently.
theta (Harmony)
Diversity penalty strength; higher values push harder for batch mixing.
LISI
Local inverse Simpson's index: the effective number of batches (iLISI) or cell types (cLISI) around each cell.
Pseudobulk
Summing counts over cells of one type per sample, giving proper replicates for DE testing.
