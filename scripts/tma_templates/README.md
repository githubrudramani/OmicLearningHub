# Example inputs for the Xenium TMA case study

Copy these into `xenium_tma_results/curated/` and replace the example rows with your own TMA map.

* `tma_layout_<slide>.csv`: one row per map position: `core_number`, `block_id` (`Empty` for an empty spot), `map_row`, `map_col`.
* `tma_cases.csv`: one row per block: `slide`, `block_id`, `mouse_id`, `condition`, `stratum` (`none` if unused), plus any per-animal columns.

All values here are made up.
